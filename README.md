# 내친구 포밍뿌 (Pomingu)

야후 꾸러기 **내친구 포밍뿌** 스타일의 캐릭터 키우기 게임 프로토타입입니다.

## 플레이 방법

GitHub Pages로 배포된 주소로 접속하면 됩니다.

## 포함 내용

- 캐릭터 선택 (포롱이, 밍뚜, 뿌비)
- 기본 육성 루프 (밥주기, 목욕, 놀아주기 등)
- 상점 / 미니게임
- 로컬 저장
- CSS 기반 idle 애니메이션

## 배포 방법 (GitHub Pages)

1. 이 폴더 전체를 새 GitHub 저장소에 업로드
2. Settings → Pages → Source: `main` / root
3. 몇 분 후 `https://아이디.github.io/저장소이름/` 으로 접속
